# 音频转录工作流

> 使用本地 AI CLI + OpenAI Whisper 实现离线音频转录

---

## 用途

将 **mp4、mp3、m4a、wav** 等音视频文件转换为文本，适用于：

- 会议记录整理
- 播客/视频内容提取
- 访谈/演讲文字稿生成
- 长音频内容意图分析与总结

## 原理

通过 AI CLI（如 GitHub Copilot CLI、Claude Code CLI 等）调用本地 Whisper 模型进行语音转文字：

```
音频/视频文件 → ffmpeg 预处理 → PyTorch + OpenAI Whisper (本地推理) → 文本输出
```

核心组件：

- **OpenAI Whisper**：开源语音识别模型，支持中文/英文等多语言
- **PyTorch**：模型推理引擎，支持 GPU 加速
- **ffmpeg**：音视频格式转换与预处理
- **AI CLI**：通过自然语言指令驱动整个转录工作流

## 优势

| 特性 | 说明 |
|------|------|
| **隐私安全** | 转录过程完全离线，内容不经过互联网，无需担心泄露 |
| **无监管限制** | 不依赖任何云服务，不受网络审查或传输限制 |
| **本地加速** | 利用 NVIDIA GPU 加速，60 分钟音频约 8 分钟完成 |
| **跨平台 AI 驱动** | 通过 AI CLI 用自然语言指令驱动，适合二次开发 |

## 系统要求

### 硬件

- **CPU**：任意现代处理器
- **GPU**（可选，推荐）：NVIDIA 显卡，6GB 以上显存（如 RTX 3060）
- **内存**：16GB 以上
- **存储**：10GB 以上可用空间

### 软件

- **操作系统**：Windows 10/11（通过 Git Bash 或 WSL）
- **Python**：3.10 ~ 3.14
- **NVIDIA 驱动**：支持 CUDA 12.x（使用 GPU 时）

## 快速开始

### 第一步：准备音频文件

将要转录的 mp3/mp4/m4a 文件放到工作目录

### 第二步：发送指令给 AI CLI

将以下指令发送给 AI CLI（根据实际文件路径修改）：

```
参考 音频转录工作指南.md，帮我转录 文件名.mp3
```

### 第三步：等待完成

AI 将自动完成以下工作：

1. 检测并配置 pip 国内镜像（阿里云）
2. 安装 ffmpeg（如未安装）
3. 安装 PyTorch（CPU 版，首次约 2 分钟）
4. 安装 Whisper 及依赖
5. 执行转录，输出 `.txt` 文件

**首次部署时间**：约 5-10 分钟（含 CPU 版 PyTorch + Whisper）

**GPU 转录时间**：60 分钟音频约 8 分钟（RTX 3060）

**CPU 转录时间**：60 分钟音频约 30-60 分钟

## 常见问题

**Q：需要联网吗？**

A：仅安装依赖时需要联网。安装完成后，转录过程完全离线。

**Q：没有 NVIDIA 显卡能用吗？**

A：可以，使用 CPU 版本，速度较慢但能正常工作。

**Q：转录准确吗？**

A：Whisper small 模型对中文普通话准确度较高，复杂口音或专业术语建议使用 medium 模型（需 GPU）。

**Q：支持哪些语言？**

A：Whisper 支持中文、英语、日语、韩语等 100+ 语言，指定 `--language Chinese` 或 `--language English` 即可。
